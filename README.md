# IESolarSales_CIS7
Inland Empire Solar Sales Route Program by Zach Huntsinger

## Project Description

The IE Solar Route Program is a C++ application. The program will allow users to:
- View city travel connections as an adjacency list
- View the  graph as an adjacency matrix
- Display all travel route variations starting from Riverside
- Determine the shortest and overall cost of the route based on the informatin provided by the user

---

## Program Functionality

The program uses a menu to allow the user to view different functions. When the program starts, the user is presented with a list of numbered options. 
- 1 - Display the adjacency list of cities and distances
- 2 - Display the adjacency matrix
- 3 - Display both the adjacency list and adjacency matrix
- 4 - Display all possible route variations starting from riverside
- 5 - Calculate and display the shortest and lowest-cost route
  - If this option is selected, user should enter additional information for MPG and Price per gallon.  
- 0 - Exit the program

After each option, the program returns to the main menu. Select 0 at the menu to exit the program.
